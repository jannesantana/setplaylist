Being a big fan of live music, everytime I go to a concert, I like to create a playlist containing the approximate setlist of each concert. However, I went to so many concerts that I decided to automate this process.

This is a prototype of a project I call _setplaylist_ which creates a spotify playlist based on a given setlist published on setlist.fm. It can support several bands/artist for the same concert (I usually go to metal concerts, which usually have 2-3 opening and a headliner). 

The next goals are:
* Create a user interface such that I just enter the list of URL stacked on top of each other. Start with a window prompt that asks for the playlist title, then prompts another window that asks for the URLs
* Make it exportable (people can use locally)
